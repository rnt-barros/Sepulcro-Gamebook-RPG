# Sepulcro - Gamebook RPG

Este é um jogo de aventura interativa desenvolvido como trabalho final de período. O projeto utiliza uma narrativa ramificada onde as decisões do jogador impactam diretamente o progresso e o desfecho da história.

## 🛠️ Tecnologias Utilizadas

- **JavaScript (ES6+):** Responsável pela lógica de navegação e manipulação dinâmica da história.
- **JSON:** Utilizado como banco de dados para estruturar a narrativa, permitindo uma separação clara entre a lógica do motor do jogo e o conteúdo textual.
- **HTML5 & CSS3:** Estruturação da interface e estilização visual do ambiente de jogo.

## 🚀 Diferenciais Técnicos

- **Manipulação de Dados:** O jogo consome um arquivo `historia.json`, o que demonstra conhecimento em gerenciamento de dados estruturados.
- **Lógica de Estados:** Implementação de um sistema de escolhas que altera o fluxo do código com base nas ações do usuário.
- **Desenvolvimento Colaborativo:** Projeto realizado em equipe, aplicando conceitos de controle de versão e integração de código.
